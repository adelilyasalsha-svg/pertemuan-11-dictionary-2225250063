## Struktur Folder
- latihan/: enam latihan dictionary Python
- praktik/data_mahasiswa.py: program pengelolaan data mahasiswa

## Cara Menjalankan
Jalankan perintah berikut di terminal:

python praktik/data_mahasiswa.py

Untuk menjalankan latihan, gunakan contoh:

python latihan/06_fungsi_dictionary.py
